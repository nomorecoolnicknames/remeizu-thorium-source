# ReMeizu MediaTek common device trees

LineageOS 16.0 common configuration for Meizu MT6750/MT6755 boards.
`device/meizu/mt6755-common` supplies shared build, init, policy and compatibility
code; each device directory supplies its own product, board and kernel settings.

Provide the matching LineageOS platform, kernel source/prebuilt and per-device
vendor inputs. M3s/U10/U20 stockgraph products check dependency graphs only;
see their `stockgraph/README.md` files for commands.
