# ReMeizu Thorium · Android 13

This branch carries the experimental unified [Meizu M3 Note M681/L681 configuration](device/meizu/m3note) for LineageOS 20.0. Per-revision device-tree identity, VINTF, vendor profiles and installer guards are implemented; complete two-board hardware operation is not accepted.

Other directories are inherited common-tree sources and do not imply Android 13 support for every model. U10/U20, M3s and the Android 9 M3 Note line belong to the maintained [lineage-16.0 branch](https://github.com/nomorecoolnicknames/remeizu-thorium-source/tree/lineage-16.0). This repository alone is not a complete platform/vendor/kernel checkout.

See the device README for module status, required external inputs and deployment limitations. Keep upstream copyright and license notices.
