# ReMeizu Thorium · Android 11

This branch carries the unified [M3 Note M681/L681 Android11 device configuration](device/meizu/m3note). It retains independent board/kernel/vendor identities. Full two-board hardware operation is not accepted.

Other common/thin directories are inherited source foundations. Their presence is not proof of Android11 build or hardware support. Restricted vendor inputs and source-built kernel images remain separate. See the device README for module ownership and acceptance limits.
